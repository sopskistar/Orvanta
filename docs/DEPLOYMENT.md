# Launch Orvanta on Vercel

Vercel is the intended host. Neon is the intended database for later private enquiry storage and automation. The marketing site is a static Next.js export and does not connect to a database. Do not add Neon, Calendly, an email provider or Retell credentials to publish it.

**Ready to deploy means the code is checked and uploaded. It does not mean a public website is already published.** Only a successful Vercel production deployment and its returned public URL establish that. No plan purchase or upgrade is authorised by this guide.

## Actual project configuration

| Dashboard setting | Value |
| --- | --- |
| Git repository | `sopskistar/Orvanta` |
| Production branch | `main` |
| Framework preset | `Next.js` |
| Root directory | Repository root (`./`; leave the field unchanged) |
| Node.js version | `24.x` (the verification runtime) |
| Install command | `npm ci` |
| Build command | `npm run build` |
| Output Directory override | **Off** — keep the Next.js preset's default |
| Local static export directory | `out` (generated by `output: "export"` in `next.config.ts`) |
| Database / storage integration | None for this launch |

Do not change the framework to Other or set the output to `.next` manually. The Vercel Next.js integration understands this export. `npm start` is the local preview server, not the Vercel build command. Official reference: [Next.js on Vercel](https://vercel.com/docs/frameworks/full-stack/nextjs).

## Environment variables

**Required user-supplied secrets: none. Required database variables: none.**

| Variable | When to set it |
| --- | --- |
| `NEXT_PUBLIC_HOSTING_PROVIDER=vercel` | Recommended for Production so the Privacy page names the actual host. |
| `VERCEL_PROJECT_PRODUCTION_URL` | Supplied by Vercel; enable automatic System Environment Variables. Do not invent or manually type a hostname for this system variable. |
| `NEXT_PUBLIC_SITE_URL` | Optional explicit HTTPS-origin override after Vercel gives you the actual production URL. Use no page path. Useful if you later add a custom domain. |
| `NEXT_PUBLIC_CONTACT_EMAIL` | Optional; omit to keep `julianahonour@gmail.com`. |

The app uses `NEXT_PUBLIC_SITE_URL` first, then Vercel's production system hostname for canonical URLs, sitemap and social images. If neither is available, it omits invented absolute URLs. Adding or changing a public build variable requires a redeployment. See [Vercel system variables](https://vercel.com/docs/environment-variables/system-environment-variables).

Do not set `DATABASE_URL`, a Neon connection string, Retell keys, Resend keys or Calendly settings for this launch. Future server credentials must never have a `NEXT_PUBLIC_` prefix. `.env.example` describes configuration; real `.env` and `.env.local` files are ignored and must not be committed.

## Exact remaining dashboard steps

1. Sign in at `https://vercel.com` with your GitHub account. Select the intended Vercel team/account.
2. Select **Add New → Project**. Find **sopskistar/Orvanta** and click **Import**. If it is absent, use the GitHub connection's repository-access settings to grant Vercel access to this repository. If it was already imported, open that existing project instead of creating a duplicate.
3. Check the settings in the table above. On an existing project, check **Settings → Git** for the repository and production branch, and **Settings → Build and Deployment** for commands and Node version. Do not create a database in Marketplace/Storage.
4. In **Environment Variables**, add `NEXT_PUBLIC_HOSTING_PROVIDER` with value `vercel` for Production. Leave the contact email override unset unless you intend to change it. Ensure automatic System Environment Variables are enabled.
5. Click **Deploy** for a new project. For an existing project, the push to `main` should trigger a production build; open **Deployments** and check the newest commit. If needed, choose **Redeploy** on that deployment. Read the build log if it fails rather than adding credentials at random.
6. Wait for **Ready**, click **Visit**, and copy the actual production URL Vercel displays, normally `https://….vercel.app`. A custom domain is unnecessary. Use the production project URL, not a local address or a login-protected preview URL.
7. If the generated metadata/sitemap does not use that production origin, add `NEXT_PUBLIC_SITE_URL` with the exact returned HTTPS origin in **Settings → Environment Variables → Production**, then **Redeploy**. Never use the example hostname from `.env.example`.
8. Open the production URL in a private/incognito browser while signed out. It must load without a Vercel account. If it requires sign-in, review **Settings → Deployment Protection** for the production deployment.
9. Complete the public checklist below. Then send that home-page URL to Retell support for manual account verification. No ID or selfie is uploaded through this website.

Vercel's [Hobby terms](https://vercel.com/legal/terms) restrict that plan to personal/non-commercial use. Vercel remains the intended host; use an account/plan authorised for this business use or resolve eligibility with Vercel. Nothing in this work purchases or upgrades a plan automatically.

## Check the published result

- Visit `/`, `/services/`, `/demo/`, `/contact/` and `/privacy/` on desktop and phone. Follow the menu and footer links.
- `/demo/` should show **Mia — cleaning enquiry demo**. Press Play; verify picture and sound, pause, seek and fullscreen. Duration is approximately 1:57 and it must not autoplay. The MP4 remains unchanged.
- Check the page copy does not claim live telephone deployment, automatic email or confirmed booking. Sample Home Cleaning is not presented as a paying customer.
- No testimonials heading or empty space should appear while `src/content/testimonials.ts` contains an empty list.
- Click **Email Orvanta** on Contact. Confirm `julianahonour@gmail.com` is the recipient. If no email app opens, copy the visible address into Gmail. An actual message is sent only when you send it from your email service; the website does not simulate message delivery.
- Open `/demo/Orvanta_Receptionist_Demo.mp4` directly if the player fails. Check exact filename/case and that this asset was included in the deployment.
- Open `/brand/social-preview.png`, `/favicon.svg`, `/robots.txt` and `/sitemap.xml`. The sitemap should list the five real production URLs; social metadata should use the same public origin.
- Visit a nonexistent path and confirm the custom 404 appears.

Local browser tests establish repository functionality; they do not establish public Vercel access or inbox delivery. Verify the actual public URL before sending it to Retell.
